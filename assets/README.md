# Assets

Small application icons and static UI assets belong here. AI model binaries do not.

- `app-icon.svg` is the source design of the app icon (a speech bubble with two caption lines).
- `app-icon.ico` (16-256 px) and `app-icon-256.png` are generated from that design by `scripts\make-icon.ps1`.
  The executable and the system-tray icon use `app-icon.ico`.
