# Offline language packs

Open **Live → Language packs…**, or **Settings → Offline language packs**.

1. Choose an output language. This shares the same pending selection as Live.
2. Click **Download selected language pack**. First use also installs isolated local translation tools; it does not change your system Python. Download progress shows actual received size and, when available, percentage. **Cancel language action** stops the operation; already installed packs are kept.
3. The downloaded pack is loaded into memory. Return to Live and **Apply** to activate the output-language choice.

The installed list shows readable directions such as **English → Spanish**. Language packs are directional. Auto-detected incoming speech can still be translated via English into your chosen language. English captions already use Whisper's local speech model and need no extra text-translation pack. These packs do not replace or speed up speech recognition itself.

## Preloading for less first-caption delay

**Preload installed pack now** loads an installed translation model before the first caption needs it. Optionally enable **Preload the output pack when I apply language settings**, then Apply/save. This preference is off by default, performs no automatic downloads, and uses additional memory. At most two translation models are cached; using different reply languages can evict a previously loaded pack. Closing the app releases that cache. No sample message, caption, or OSC reply is generated by preloading.

Downloading another pack does not hold the active translation worker's processing lock. Installed translations can continue during a download. Initial runtime setup and model preloading themselves still consume CPU, disk, and memory; install before a busy VR session when practical. Unsupported pairs, missing tools, and incomplete packs show an actionable status rather than being reported as ready.
